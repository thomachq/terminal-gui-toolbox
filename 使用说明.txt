Terminal GUI Toolbox —— 多协议终端工具箱
==========================================

双击 TerminalToolbox.exe 直接运行。不需要装 Python，也不需要开命令行。
首次启动要解压依赖，会慢 3-5 秒；之后每次约 2-3 秒。


这一版是什么
------------
原来只做 NAS 隧道证书的 Client Cert Console，现在扩成一个工具箱：
SSH / Telnet / 本机三种会话，连上自动认出对方的系统和设备类型，
命令按系统自动切换写法，底部实时显示性能，右侧常驻一个能自己动手的
智能运维助手（能看、能执行、事后能翻日志）。隧道客户端证书管理只是其中一页。


v1.0.8 更新
-----------
· 模型管理改成两级（对齐 Cherry Studio 的「模型服务」）：
  左边选供应商（DeepSeek 官方 / Ollama / LM Studio / Harness / 自定义），
  右边管这家供应商下面的模型。接口地址和 API Key 在供应商那一层填一次，
  下面所有模型共用；换网关只改一个地方，不用逐个模型改。
  在某个供应商下新增模型时，地址和 Key 会自动继承过来。
· 表格列宽终于能拖了。以前拖完一松手就弹回最小宽度 —— 原因是内容比面板宽时
  Tk 会把「可拉伸」的列压回 minwidth，任何一次重绘都会触发。现在列宽由程序自己
  算：余量只补给填充列、内容超宽就交给横向滚动条，拖过的宽度会记住。
· 主机清单里「本机」那一行的地址显示 localhost（以前是破折号「—」，看着像没填完）。

  每次改之前自动把当前规则原文备份到 data\fw_backup\，改完能「撤销上一步」。
· 路由表：新增、编辑、删除、设为默认都能在界面上做（Linux 用 ip route replace 一步换默认），
  同样有备份与撤销。
· 隧道客户端证书控制台去掉了重复的「连接」页 —— 它跟着主机管理里连好的那台设备走；
  没连设备时头部会提示，并给一个「主机管理」跳转按钮。
· 窗口：启动高度按屏幕自适应；记住退出时的位置、大小、是否最大化；
  窗口缩小导致左侧导航装不下时出现滚动条；拖动缩放不再卡。
· 点 × 现在就是退出。以前默认「关窗口收进托盘」，可 Win11 会把新图标塞进
  右下角的「︿」溢出区，结果是窗口没了、进程还在、图标又找不到，只能去任务管理器
  强杀。现在托盘改成显式开关（设置中心 →「关闭窗口时收到托盘」，默认关）；
  打开后真收进托盘时会弹一个自绘小提示，告诉你图标在哪、怎么彻底退出。

页面清单（按左侧导航顺序）
--------------------------
1) 连接与设备
   选协议（SSH / Telnet / 本机）→ 填地址端口用户 → 选私钥或密码
   → 点「连接并探测」。连上后右边会逐项列出系统、内核、架构、主机名、
   设备类型、Shell、当前用户。

   · 选「本机」时，档案、地址、端口、用户、私钥这些全收起 —— 本机没有
     「连到哪台设备」这回事，界面只剩一项提权设置：
       Windows：勾「以管理员身份运行（UAC）」，勾了会重开一个管理员窗口，
                旁边直接写着当前是不是管理员。本机 Windows 没有 sudo，
                所以这里没有 sudo 密码框。
       Linux：  勾「使用 sudo 提权」并填 sudo 密码，连上后自动执行 sudo -i。
   · 远程的提权只有一个密码框，含义由**探测出来的设备类型**决定，不由协议决定：
       服务器 / Linux / macOS → sudo（自动 sudo -i）
       交换机 / 路由器        → enable 特权模式
     所以同一个 SSH，连服务器是 sudo，连交换机就是 enable；Telnet 反过来也成立。
     连上先探测、再按结果提权，不会先假定对方是什么。
   · 不勾选也能用：第一次遇到需要 root 的操作，程序会弹窗问你要密码，
     密码只在内存里留到关窗口为止。也可以自己到「终端」里敲。
   · 交换机 / 路由器（Cisco、H3C、华为、锐捷）会自动认出厂商，
     命令改成该厂商的写法（show 或 display、ip route 或 ip route-static），
     分页提示（--More--）会自己翻过去，不用人守着敲空格。
   · 协议和设备类型是两件事：SSH 一样能连交换机 / 路由器（会开一条持久
     shell，配置视图能保持，路由一样改得动），Telnet 也一样能连 Linux
     （提权走 sudo，不是 enable）。

   多设备：顶部那排标签就是已连接的设备，连几台就有几个。点一下切过去，
   路由表、防火墙、Docker、Web 服务、AI 运维这些页立刻改看那一台；
   标签上的 × 只断那一台，其余的连接不受影响。全断完自动回到「本机」。
   同一台设备重复连接不会堆出两个标签，直接替换旧的。
2) 网络工具
   Ping 测试 / 路由追踪 / IP 地址 / 路由表 / 监听端口 / DNS 配置。
   命令按对方系统自动选：Linux 用 ip -4 addr，macOS 用 ifconfig，
   Windows 用 ipconfig /all；ping 次数 Linux 是 -c，Windows 是 -n。
   Ping 结果会压成一行：发送 4 · 接收 4 · 丢包 0% · 平均 0 ms。
   结果有两页签：「表格」是解析后的样子，「原始输出」是命令原样回显。

3) 系统信息
   版本信息 / 负载 / 磁盘 / 进程 TOP，磁盘和进程都是表格，能点表头排序。

4) 文件管理（仿 MobaXterm 的 SFTP 面板）
   左上角分三段：设备（只看远端）／本机（只看本机）／双栏（上下各一半）。
   默认是「设备」，列表能占满高度。
   · 双击目录进目录；双击文件就直接传（远端→本机 或 本机→远端）
   · 「上传 →」「← 下载」：双栏时传选中的那个，单栏时弹文件/目录选择框
   · 整个目录也能传，会递归；一次可以排多个任务，能中途「取消」
   · 进度条会显示 1.2 MB / 8.0 MB，传完留着「上传完成 · 3 个文件 · 1.2 MB」
   · 两边都能新建目录 / 重命名 / 删除（目录是递归删，会先让你确认）
   · 装了 WinSCP 的话，「WinSCP」按钮会按当前连接直接拉起来；
     没装会告诉你地址，装完不用重启本程序

5) 路由表
   v1.0.7 起能直接在界面上改：新增、编辑、删除、设为默认。
   Linux 用 ip route（换默认用 replace，一步到位）、Windows 用 route
   （勾「永久」会加 -p 写注册表，重启还在）、macOS/BSD 用 route -n。
   每次改之前把当前路由表原文备份到 data\route_backup\，改完能「撤销上一步」。
   加/改/删都要权限：没给 sudo 密码时会弹窗问一次，给了就自动带上；
   本机 Windows 则要整个程序以管理员身份运行。

6) 防火墙
   v1.0.7 起进页面就**自动探测**这台设备用的是哪一套：ufw → firewalld →
   nftables → iptables（Windows 是 netsh advfirewall，macOS 是 pf，
   FreeBSD 是 pf/ipfw），先探到「正在用」的那个就停，不会一股脑全跑。
   列表能直接改：新增规则、编辑、删除、启用/停用（Windows 支持单条启停）、
   上移/下移（ufw 与 iptables），双击一行就是编辑。
   写之前自动把当前规则原文备份到 data\fw_backup\，并且**先给你看要执行的命令**，
   确认了才跑；跑完记一条审计，界面上能「撤销上一步」。
   例外：macOS 的 pf 只读 —— 它要改 /etc/pf.conf 再 reload，不适合逐条改。

7) Docker
   先判断这台设备到底有没有 Docker，再说话：
   · 没装      → 标题写「当前设备未安装 Docker」，并告诉你装什么
   · 装了没跑  → 「已安装但守护进程没有运行」+ 怎么启
   · 没权限    → 「无权访问」+ 加 docker 组，或填 sudo 密码
   · 能用      → 容器 / 镜像 / 资源占用三张表，可启停、重启、看日志、删除

8) Web 服务
   一台机器上可能同时跑着好几个 Web 服务，所以这一页先「数清楚有几个」，
   再用下拉列表切换，每个服务各管各的配置与证书。
   认得出来：Nginx / Apache / Tomcat / Caddy / Lighttpd / IIS。
   · 怎么认    进程名 + 命令行（Tomcat 认 -Dcatalina.base）、监听端口、配置文件三方对照；
               Tomcat 的监听进程叫 java，光看进程名认不出来，所以拿 pid 回 ps 里对
   · 服务详情  版本、是否运行、监听端口、systemd 单元、配置文件、站点根目录、运行用户
   · 证书      读服务正在用的证书：主题、颁发者、SAN、到期时间、剩余天数
               （剩 30 天内标黄、过期标红）、是不是自签、链有几张、私钥配不配对
   · 导入部署  选本地证书与私钥 → 校验是不是一对 → 填设备上的目标路径 →
               备份成 .bak-时间戳 → 写入（私钥 600）→ 回读 sha256 → 配置检查 → 重载
               任何一步失败都会自动还原再重载，不会留半套文件
   · 恢复备份  把最近一次的 .bak-* 退回原位并重载
   · IIS       证书是 http.sys 的端口绑定，不是配置文件路径，所以只做「看」，
               换证书请在 IIS 管理器导入 PFX 或 netsh http update sslcert 重新绑定

9) 隧道客户端证书管理
   证书功能已经内嵌在这一页里，不再单独开窗口。
   上面几个分段页：证书 / 打包 / 部署 / 命令日志。
   v1.0.7 去掉了原来那个「连接」页 —— 跟主机管理重复（那里已经能连了）。
   现在它**跟着主机管理里连好的那台设备走**：头部写着「当前设备：user@host」，
   没连设备时提示「先在主机管理里连接一台设备」并给一个跳转按钮；
   部署需要的提权也沿用那台设备在主机管理里的设置（Linux 的 sudo / Windows 的管理员）。
   「部署」页多了「探测当前设备」按钮，读的是当前会话上的服务端现状，
   不再单独连一台。单独运行 VPNCertConsole.exe 时仍然有「连接」页，用法不变。
   功能与原来的 Client Cert Console 完全一样（建 CA、签证书、每个平台一份配置文件、部署），
   默认 CA 名称是 Client Cert CA，可以改。
   数据还是主程序这一份 data 目录。

右侧常驻：智能运维助手
   不再是导航里的一页 —— 它在右边，换页签不会打断对话。
   说一句话（比如「看看 80 端口是谁在占，顺便把它日志翻出来」），
   AI 会一条条给命令，程序在**当前这台设备**上执行，把真实输出喂回给 AI，
   它再决定下一步 —— 最多来回几轮（默认 8 步，可在「模型设置」里改）。

   执行模式三档，在「＋ → 模式」里切换：
   · 自动执行（默认）：只读和一般改动直接跑，高风险（删除、清空、重启设备）必问
   · 每步确认：凡是有改动的命令都先弹窗给你看命令和理由
   · 只读：只跑查询类命令，改东西的一律跳过并在对话里记账
   三种模式下「高风险」都不会自动放行；也没有「本次不再问」这种开关。

   模型可以用自家 Key（DeepSeek、通义、Kimi、智谱、OpenAI 兼容的自建网关都行），
   也可以选本地 DeepSeek Harness。Key 加密存在 data/ai.json，界面上不回显。
   每条命令和输出同时进「日志管理」，事后能翻。

   技能（输入框上方那个下拉）：
   内置 8 份排查剧本，都是从宝塔终端搬过来的原文 ——
     服务器资源与性能检查 / 安全诊断与加固 / 服务与计划任务诊断 / 网络与防火墙诊断 /
     网站与 SSL 诊断 / 数据库诊断 / 日志分析 / 文件与 FTP 诊断
   每份都是「探测 → 检查 → 诊断 → 修复 → 注意事项」的顺序，AI 会照着走，
   不会一上来就改配置。选「自动判断」就按你说的话挑一份（对话里会写命中了什么）。
   点右边的「技能库」能看每份正文、导入自己的技能（.md 或 .zip，入口文件叫 SKILL.md）、
   一键打开 data/skills/ 目录。技能只是文字，里面的脚本一律不会被执行。
   删掉某个内置技能后不会被自动装回来。

11) 智能体接入（给 AI 用）
   本地 HTTP API，默认关闭，点「启动服务」才开，只在 127.0.0.1 上监听。
   端口是 30000-45000 里随机挑的空闲端口，不是固定的 8760/8768 那一类，
   免得跟别的程序撞车。端口被占了，启动时会自动换一个并在日志里说明；
   想固定端口就在「API 设置」里填个数字，留空或填 0 就是自动挑，
   换了端口要把新地址重新给智能体一份。
   给 AI 智能体的 SSH 技能用：连一次拿个会话 ID，之后反复下命令；
   服务端每 25 秒发一次 keepalive，掉线自动重连，智能体不用自己管连接。
   鉴权是 Authorization: Bearer <令牌>，令牌在页面上点「复制令牌」拿。
   接口清单可以在浏览器打开 /v1/openapi.json 看。


底部状态栏（仿 MobaXterm）
--------------------------
连上之后每 3 秒刷一次：

  [系统图标] 设备名 │ CPU 37% [迷你曲线] │ 内存 6.0/16.0 GB
  │ ↑2.0 KB/s │ ↓1.5 MB/s │ [时钟] 1 days │ 就绪 ◀ ▶ ✕

· CPU 和网络速率都是两次采样做差分算出来的
· 速率单位是字节（B/s、KB/s、MB/s），没做 bit 换算，免得标错误导
· ✕ 断开当前会话（日志都进「日志管理」，状态栏不再放折叠按钮）


日志管理（唯一的一份日志）
--------------------------
右侧那块「命令日志」面板在 v1.0.6 撤掉了 —— 两处日志重复，看着累。
v1.0.7 又把它从左侧导航挪到了**状态栏最右边的「日志」按钮**：点一下在窗口
底部拉开一条底边栏（IDE 那种），上沿能拖着调高度，再点一下收起；
开没开、多高，下次启动还是那个样子。左侧导航因此少占一格。

记的东西比以前全：运维工具跑的命令、终端里手敲的命令、文件传输、
证书签发与部署、AI 的每一步执行与审批，都按分类归好。
点一行看详情，里面是命令原文、返回码、耗时和输出（stdout / stderr 分开标）；
输出里出现过的口令、私钥正文，**落盘前就打成 ******，事后翻也看不到明文。


终端（默认不打开）
------------------
主界面右上角「终端」按钮点开，不看的人完全遇不到它。

· 和主界面共用同一条连接：程序执行的命令、你手敲的命令都在这里
· 程序执行的会显示成「时间 ▸ 命令」，你敲的直接跟着提示符走
· 自己敲的那条不会被重复回显两遍

· 手动输入有两种形态，右上角「输入方式」里选，选过就记住：
  ① 输入框（默认）：最下面一条独立输入行，左边写着当前目录，
     输出在上面的大框里滚。想改命令就是在输入框里改，不会碰到旧输出。
  ② 行内：跟真终端一样，提示符直接落在正文里，命令和结果排在一条流里。
     光标和退格翻不过提示符；上方来的输出插在提示符前面，
     正在敲的字不会被冲掉；cd 之后那条提示符会当场换成新目录。
  切换形态时敲到一半的内容会跟着搬过去。

· 内建命令：clear 清屏、cd <目录> 换目录、history 历史、help、exit
· ↑ ↓ 翻历史，Ctrl+L 清屏，Ctrl+C 放弃等待（设备上的命令可能还在跑）
· 头部「同步主程序命令」可以关掉，只留自己敲的
· 输出里的私钥正文同样会被打码，见下面「关于私钥的显示」


关于 PuTTY 私钥（重要）
-----------------------
本程序读不了 PuTTY 的 .ppk 格式。如果你的钥匙是 .ppk：
  用 PuTTYgen 打开它 → Conversions → Export OpenSSH key
  → 另存为不带扩展名的文件 → 在「浏览…」里选它。
选完文件下方会显示「类型 + 位数 + SHA256 指纹」，用来核对是不是那把钥匙。
带口令的私钥：先在「私钥口令」填口令，指纹会自动重算，不用重新选文件。


加密
----
· 连接档案 data\profiles.dat 整个文件是密文，用记事本打开也看不到
  主机、用户名、密码中的任何一个字。
· 密钥是 data\.vpncert-key。它必须和 exe 一起搬，
  单独拷走 profiles.dat 到别的电脑是解不开的（这是好事）。
· 每个口令框后面都有自己的「保存口令」：私钥口令、登录密码、提权密码
  各勾各的，勾哪项才存哪项，没勾的一个字都不写进密文档案。
  只勾「私钥口令」就只存私钥口令，不会连带把没勾的两项也存进去。
· 强度要说清：密钥就在同一个 data 目录里，所以这是防「明文被顺手看到、
  被搜索、被同步到网盘」，不防拿到整个文件夹的人。便携和保密是对立的，
  这里选了便携。


应用锁
------
标题栏右上角「设置锁」：

· 设过密码后，启动需要解锁；闲置超过设定分钟数自动重新锁定（0 = 永不）
· 落盘的是 PBKDF2 校验值，不是密码本身；校验迭代 20 万次
· 勾「记住密码」→ 用本机密钥存一份，启动自动解锁
· 密码至少 6 位，中英文符号都能用，但不能全是同一个字符
· 已设锁时点右上角按钮会弹出：立即锁定 / 锁设置 / 关闭应用锁
· 改密码、关锁都必须先输对**当前密码**，忘了只能删 data\settings.json 重设
  （档案和 CA 不受影响）

锁的是界面。锁定或退出会同时断开连接，解锁状态不会残留。

右上角还有一个「深色」按钮切主题，设置会记住。

托盘
----
点右上角的 × 就是退出（会话会断），不再偷偷驻留。

想让程序退到后台，到「设置中心 → 窗口与日志 → 关闭窗口时收到托盘」打开。
打开后点 × 会收进系统托盘：图标一般在任务栏右下角的「︿」溢出区里，
可以把它拖到任务栏常驻。托盘菜单有显示主窗口 / 状态 / 应用锁设置 /
启动 API 服务 / 隐藏到托盘 / 退出。
真要结束进程，用托盘右键菜单里的「退出」——只收进托盘不算退出。


关于私钥的显示
--------------
私钥正文在任何界面都不会显示。只要输出里出现这些块，就整块换成
「[私钥内容已隐藏，共 N 行]」，首尾 BEGIN / END 标记留着：

  -----BEGIN ... PRIVATE KEY-----     （OpenSSH / RSA / EC / PKCS#8）
  -----BEGIN OpenVPN Static key V1----- （ta.key）
  PuTTY .ppk 的 Private-Lines 段落

管到的地方：执行过的命令与输出、网络工具输出、系统信息、实时终端（含你自己手敲的
cat 命令）、VPN 控制台的命令日志与部署输出、给 AI 智能体用的本地 API。
命令行里内联的 --password / --passphrase / *PASSWD= 值会变成 ******。

界面上最多显示路径、类型、位数和 SHA256 指纹。


数据在哪
--------
就是本文件旁边的 data 文件夹：

  data\.vpncert-key   档案加密密钥（务必和 exe 一起搬）
  data\profiles.dat   连接档案（密文）
  data\settings.json  应用锁状态（只有校验值，没有密码）
  data\ca\            CA 私钥与证书
  data\devices\       各设备证书
  data\output\        打包产物

重要：不要删 data。删了等于把 CA 丢了，之前签出去的所有证书全部作废，
只能重新建 CA 并逐台设备重发。


注意
----
· 导出的配置文件内嵌了客户端私钥，等于把私钥交给持有者，请控制分发范围。
· 吊销证书后，记得在这一页的「部署」分段里把新的 crl.pem 推到 NAS，
  否则被吊销的设备仍然连得上。
· 改 NAS 端「要求客户端证书」之前，先把所有设备的证书签好、配置发下去，
  否则已有客户端会立刻连不上（详见 README 的上线顺序）。
· 文件夹里那个旧的 VPNCertConsole.exe 已经不需要了。
  这一页现在是主界面的一部分，点左导航「隧道客户端证书管理」即可，
  不再另开窗口、也不再需要 --vpncert 参数。
